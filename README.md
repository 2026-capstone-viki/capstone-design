# Team VIKI Capstone : 프롬프트 최적화 기반 지능형 AI 응답 시스템 개발

## 개요
본 프로젝트는 사용자의 다양한 질문 의도와 요구 성능을 실시간으로 분석하여 최적의 AI 모델을 동적으로 매칭하는 **지능형 AI 컨트롤 타워** 시스템을 구축하는 것을 목표로 한다. 단일 모델의 성능적·비용적 한계를 극복하기 위해 **OpenRouter(통합 API)** 플랫폼을 활용하여 글로벌 Top-tier LLM들을 연동하고, 상호 평가 기반의 앙상블 학습 기법을 적용하여 신뢰성 높은 최적의 답변을 제공한다.


- **과제 배경**
  - 단일 LLM 사용 시, 특정 도메인(예: 코딩, 논리 추론, 일반 상식)에 따른 답변 품질의 편차 발생
  - 모든 질의를 고성능 유료 모델로 처리할 경우, 과도한 API 비용 발생 및 예산 관리의 한계
  - 단순 카테고리 분류 모델만으로는 복잡한 질문의 맥락을 정확히 파악하기 어려움

- **과제 목적**
  - OpenRouter API를 통한 다종 LLM(Claude, GPT, Grok 등)의 단일 엔드포인트 통합 및 제어
  - 모델 간 상호 평가(Peer Review) 및 유료 모델 가중치(1.5배)를 적용한 가중 투표(Weigthed Voting) 앙상블 알고리즘 구현
  - '단순 분류 방식'과 '앙상블 학습 적용 후 분류 방식'의 비교 분석을 통한 시스템 고도화 및 비용 효율성 증명

---

## 주요 기능
1. **지능형 컨트롤 타워 백엔드 (`Backend/`)** - OpenRouter 통합 인터페이스 환경 구축 및 5종 멀티 모델 API 연동
     *(대상 모델: Claude 3.5 Sonnet, GPT-4o-mini, Grok 2, Gemini 2.5 Flash, Llama 3.3)*
   - 실시간 토큰 소모량 모니터링 및 한도 관리를 위한 선불 충전(Prepaid Credits) 기반 비용 통제 로직

2. **상호 평가 및 가중 투표 알고리즘 (`Ensemble/`)** - **메타 추론(Meta-Reasoning)**: 질문 유입 시 각 LLM이 해당 질문을 가장 잘 처리할 수 있는 최적의 모델을 상호 추천
   - **가중 투표 시스템**: 추론 능력이 뛰어난 유료 API 군에 1.5의 가중치를, 무료/저가형 API 군에 1.0의 가중치를 부여하여 다수결 원칙에 따라 최종 답변 모델 결정

3. **Streamlit 기반 웹 사용자 인터페이스 (`Frontend/`)** - **실시간 대화 UI**: `st.session_state`를 활용하여 ChatGPT 스타일의 대화 기록 유지 및 메시지 누적 표시
   - **데이터 내보내기**: 시연 및 분석을 위해 전체 대화 로그를 JSON/TXT 파일로 내보내는 기능
   - **앙상블 분석 대시보드**: 모델별 투표 현황 및 라우팅 결과, 소모 예산 통계를 시각화하여 실시간 대조

## 폴더 구조
- `Frontend/` – Streamlit 기반 웹 어플리케이션 소스 코드
- `Backend/` – OpenRouter API 연동 및 서버 라우팅 파이프라인
- `Ensemble/` – 모델별 상호 평가 및 가중 투표 알고리즘 구현 모듈
- `Config/` – API 엔드포인트 및 모델 가중치(1.5 / 1.0) 설정 파일
- `LICENSE` – MIT 라이선스
- `README.md` – 프로젝트 개요 및 사용법

## 사용 예시
1) 개발 환경 및 필수 패키지 설치 (`langchain-openai`, `streamlit` 등)
2) `Config/` 내 OpenRouter API Key 및 선불 크레딧 한도 설정
3) Streamlit 웹 서버 실행을 통한 실시간 지능형 컨트롤 타워 가동
4) 사용자 질의 입력 시, **[상호 평가 ➔ 가중 투표 ➔ 최적 모델 배정 ➔ 대시보드 시각화]** 파이프라인 수행
