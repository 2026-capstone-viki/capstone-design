# Team VIKI Capstone : 프롬프트 최적화 기반 지능형 AI 응답 시스템 개발
> **Google Colab 개발 환경**에서 단일 주피터 노트북(.ipynb) 파일 내에 **Streamlit 웹 UI + OpenRouter 백엔드 파이프라인**을 모두 통합하여 로컬터널(Localtunnel)을 통해 구동하는 독립형 아키텍처입니다.

## 개요
본 프로젝트는 사용자의 비정형 질문 의도와 요구 성능을 실시간으로 분석하고, 최적의 전문가 AI 모델을 동적으로 매칭하는 **지능형 AI 컨트롤 타워 허브** 구축을 목표로 합니다.

단일 LLM이 가지는 도메인별 성능 편차와 고비용 유료 API 독점 문제를 해결하기 위해, **OpenRouter 단일 엔드포인트**를 기반으로 글로벌 상위 모델들을 연동했습니다. 본 시스템은 앙상블 학습을 적용하지 않은 **단일 라우팅 모델(자체 단일 Llama 배정 방식)**을 대조군으로 삼아, **다종 모델 간 상호 평가(Peer Review) 및 다수결 투표(Majority Voting) 앙상블 시스템**이 도메인 판정 정확도와 신뢰성을 얼마나 정량적으로 향상시키는지 입증하고자 합니다.

- **과제 배경**
  - 단일 LLM 사용 시, 특정 도메인(예: 코딩, 논리 추론, 일반 상식)에 따른 답변 품질의 편차 및 환각(Hallucination) 리스크 발생
  - 모든 질의를 고성능 유료 모델로 일괄 처리할 경우, 과도한 API 비용 발생 및 자원 낭비의 한계
  - 단순 카테고리 분류 모델 및 정적 키워드 매칭 방식만으로는 대화 맥락이 유실된 복잡한 질문의 의도를 정확히 파악하기 어려움

- **과제 목적**
  - OpenRouter API를 통한 다종 LLM(Claude, GPT, Perplexity, Gemini, Llama)의 단일 엔드포인트 통합 및 최적 제어
  - 모델 간 상호 평가(Peer Review) 및 다수결 기반 앙상블 알고리즘을 구현하여 단일 모델의 편향적 오분류 차단
  - 앙상블을 적용하지 않은 '단일 Llama 모델 배정 방식'과 '앙상블 다수결 라우팅 방식'의 실증적 대립 실험을 통한 시스템 고도화 및 품질 개선 검증

## 주요 기능
1. **지능형 컨트롤 타워 백엔드** - OpenRouter 통합 인터페이스 환경 구축 및 5종 멀티 모델 API 연동
     *(대상 모델: Claude 4.6 Sonnet, GPT-4o, Perplexity Sonar Pro, Gemini 2.5 Pro, Llama 3.3)*
   - Sliding Window 메커니즘을 적용하여 대화 히스토리 속 생략된 주어와 지시어를 추적하고 프롬프트를 정규화하는 맥락 복원 파이프라인
   - Concurrent Futures 라이브러리를 활용한 멀티스레딩 병렬 처리로 다종 LLM에 동시 투표 쿼리를 송출하는 고속 컨트롤 타워 구축

2. **상호 평가 및 가중 투표 알고리즘** - **메타 추론(Meta-Reasoning)**: 질문 유입 시 연동된 5종의 글로벌 LLM이 질문을 교차 분석하여 가장 적합한 도메인 전문가 모델을 상호 추천
   - **다수결 투표 시스템**: 각 모델이 제출한 상호 평가 결과를 취합한 뒤, 다수결(Majority Voting) 원칙에 따라 최종 전문가 AI 모델(추론의 Claude, 범용의 GPT, 검색의 Perplexity 등)을 동적으로 확정 및 배정

3. **Streamlit 기반 웹 사용자 인터페이스** - **실시간 대화 UI**: LangChain Streamer 및 `st.write_stream`을 활용하여 실시간 답변 텍스트 스트리밍 출력 및 ChatGPT 스타일의 대화 기록 유지
   - **데이터 내보내기 및 파일 파싱**: `.py`, `.ipynb` 등 소스코드 및 문서 파일을 직접 업로드하여 분석하는 입력 인터페이스 및 대화 로그 관리 기능
   - **추론 로그 시각화**: `st.expander` 컴포넌트를 통해 원본 질문, 맥락 복원 결과, 5대 모델의 실시간 교차 투표 내역 및 배정 사유를 사용자에게 투명하게 공개하는 대시보드 구조

## 사용 예시
1) Google Colab 환경 접속 후 주피터 노트북 파일(`.ipynb`) 로드 및 필수 패키지 설치 (`langchain-openai`, `streamlit`, `localtunnel` 등)
2) 소스코드 내부 환경변수 설정 영역에 고유의 OpenRouter API Key 입력
3) 노트북 최하단 셀 실행을 통해 `localtunnel` 구동 및 외부 접속용 가상 웹 URL 주소(`*.localtunnel.me`) 확보
4) Streamlit 웹 서버 가동 및 실시간 사용자 질의 입력 시, **[맥락 복원 ➔ 상호 평가 투표 ➔ 다수결 모델 배정 ➔ 스트리밍 출력 및 로그 시각화]** 파이프라인 수행
